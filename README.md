# 🎾 Tennis Tournament Management System

A full-stack web application built to streamline the organization and management of tennis tournaments. The system offers role-based access for players, referees, and administrators, ensuring a tailored and efficient user experience for each participant.

---

## 🚀 Features

- **Role-Based Access Control**
  - **Players**: Register for tournaments, view schedules, and track match results.
  - **Referees**: Input match scores, verify results, and manage match logs.
  - **Administrators**: Create and manage tournaments, assign roles, and oversee system operations.

- **Match Scheduling & Management**
  - Automated match generation and time slot allocation
  - Real-time result updates and performance tracking

- **Responsive UI**
  - Optimized for both desktop and mobile devices
  - Clean, intuitive dashboard for each user role
